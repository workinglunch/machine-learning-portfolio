## About This Repository

This repository documents my practical journey through machine learning, combining formal study with hands-on experimentation and project development.

I am currently completing a postgraduate Certificate in Machine Learning at SETU. My background is in IT infrastructure, operations, cybersecurity and technology leadership, and I am using this portfolio to develop and demonstrate practical machine learning skills.

The emphasis of this repository is on learning by doing: understanding the data, writing the code, testing models, interpreting the results, and documenting what I learn along the way.

## Current Project: Cryptocurrency Market Analysis

My first project uses a historical cryptocurrency market dataset to explore machine learning techniques using real-world financial data.

The project begins with data exploration and preparation before progressing into different areas of machine learning.

### Planned Areas

**Data Exploration**
- Loading and inspecting the cryptocurrency dataset
- Understanding the available features
- Cleaning and preparing the data
- Working with dates and time-series information
- Visualising market behaviour

**Supervised Learning**
- Linear regression
- Feature selection
- Training and testing datasets
- Model evaluation
- Exploring the relationship between historical market variables

**Unsupervised Learning**
- Clustering cryptocurrencies based on market characteristics
- Identifying patterns and similarities within the dataset
- Exploring dimensionality reduction techniques

**Reinforcement Learning**
- Exploring how reinforcement learning concepts could be applied to historical market data
- Developing a simple experimental environment
- Comparing reinforcement-learning concepts with traditional supervised approaches
